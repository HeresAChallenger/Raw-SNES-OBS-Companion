# Contribuindo

Envie problemas do companion para o repositório do companion. Para problemas de leitura USB, detecção de jogo e RAM do RAW-SNES, consulte o repositório original de Liqui.

Execute `python -m unittest discover -s tests -v` antes de abrir uma contribuição. Não compartilhe sua Web API Key, `ra_token`, `rawsnes_config.json`, dados pessoais, arquivos RAW-SNES protegidos nem gravações sem licença.
